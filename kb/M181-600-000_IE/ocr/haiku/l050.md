7.1.11. Регулятором ПОЛОЖЕНИЕ ГОЛОВОК по стрелочному индикатору на панели регулировок установите максимальное значение, а колебания стрелки из-за качания электродвигателя минимальное.

7.1.12. Установите регуляторы в зоне УПРАВЛЕНИЕ ЧХ панели регулировок в положения, при которых уровень шумов по всем головкам будет минимальным, а четкость одинаковая по всему полю изображения.

7.1.13. Проверьте функционирование звуковых каналов с помощью индикаторов уровня и контрольного громкоговорителя.

7.1.14. Проверьте выходные сигналы канала управления по контрольному осциллографу при нажатии кнопки ВХОД КУ блока К203.

7.1.15. Остановите аппарат и зарядите его лентой, предназначенной для записи.

7.1.16. Включите режим "Подготовка" и затем "Запись". Убедитесь по индикатору токов записи, что показания прибора соответствуют подобранным оптимальным значениям тока записи видеоголовок.

7.1.17. Проверьте установку тока записи канала управления.

7.1.18. После окончания записи длительностью (10 - 15) минут перемотайте ленту и включите режим "Воспроизведение".

7.1.19. При необходимости повторите операции по п.п. 7.1.11 - 7.1.13.
