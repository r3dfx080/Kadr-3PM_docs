7.4.17. Подайте на вход осциллографа С1-64 сигнал с выхода "ВСЛВ" видеомагнитофона, развертку осциллографа установите так, чтобы синус-квадратичный импульс находился в конце развертки, для запуска развертки подайте импульс из контрольного гнезда "ССП" на блоке опорного селектора В105.

7.4.18. Воспроизведите запись и измерьте величину нестабильности импульса Δt мкс, стабильность воспроизводимого сигнала определите по формуле:

Δτ = Δt / 2 мкс

7.4.19. Переключатель режимов работы перевести в положение "3", на выходе видеомагнитофона (разъем "ВЫХОД ВСВ") подключите видеоконтрольное устройство, определите по секундомеру время, необходимое для установления изображения на экране ВКУ (синхронизацию ВКУ переключите в положение "ВИДЕО"), после нажатия клавиши "В" при воспроизведении записи по п.7.5.II.
