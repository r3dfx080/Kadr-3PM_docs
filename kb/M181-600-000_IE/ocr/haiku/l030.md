6.7.15. Намотайте отрезок ленты с петлей на бобышку левого подкассетника, вращая двигатель против часовой стрелки. Закрепите динамометр (5 - 15) Н в петле ленты. Измерьте окружное усилие (7,4 ± I) Н, повернув подкассетник с помощью динамометра по часовой стрелке.

6.7.16. Регулировка окружных усилий правого бокового двигателя в режиме "Стоп".

Намотайте отрезок ленты с петлей на бобышку правого подкассетника, вращая двигатель против часовой стрелки. В петле закрепите динамометр с пределами измерений (10 - 50) Н. Измерьте окружное усилие 34,3^{+3}_{-I} Н, повернув подкассетник с помощью динамометра по часовой стрелке.

6.7.17. Намотайте отрезок ленты с петлей на бобышку правого подкассетника, вращая двигатель по часовой стрелке. В петле закрепите динамометр с пределами измерений (5 - 15) Н. Измерьте окружное усилие (7,4 ± I) Н, повернув подкассетник с помощью динамометра против часовой стрелки.

6.7.18. В случае несоответствия усилий 34,3^{+3}_{-I} Н произведите подрегулировку положения упора электромагнита в тормозе соответствующего двигателя.

При несоответствии усилий (7,4 ± I) Н измените натяжение пружин в тормозах.

6.7.19. Регулировка усилия давления прижимного ролика при протягивании магнитной ленты.

Установите регулятор блока Т102 в положение НАСТРОЙКА.
