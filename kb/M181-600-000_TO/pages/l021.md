Восстановленный подлинник №1

а) лентопротяжный механизм служит для транспортирования магнитной ленты мимо блока вращающихся головок, записывающих или считывающих информацию;

б) панель управления и панель регулировок служит для управления работой видеомагнитофона при включении его в тот или иной режим и для осуществления оперативных регулировок;

в) система автоматического регулирования предназначена для управления скоростью вращения диска с видеоголовками и скоростью движения магнитной ленты;

г) канал изображения для преобразования входного видеосигнала в частотно-модулированный сигнал, записываемый на ленту, и обратного преобразования воспроизводимого ЧМ-сигнала в выходной видеосигнал;

д) канал звукового сопровождения, состоящий из звукового и режиссерского каналов, предназначен для записи и воспроизведения звукового сопровождения записываемой программы, а также для записи режиссерских указаний;

е) система контроля и коммутации для контроля качества работы различных блоков и коммутации рабочих режимов;

ж) система питания предназначена для обеспечения всех блоков и узлов видеомагнитофона необходимыми питающими напряжениями.

з) вакуумные системы предназначены:

Т 04 - для создания вакуума в вакуумной направляющей БВГ;

Т04.1 - для создания разрежения в полости датчика счетчика ленты Т207.
