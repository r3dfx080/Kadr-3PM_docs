## 1. ВВЕДЕНИЕ

### 1.1. Назначение ТО

Техническое описание предназначено для изучения видеомагнитофона: конструкции, принципа работы, технических данных, необходимых для обеспечения полного использования технических возможностей.

### 1.2. Состав ТО

Техническое описание на видеомагнитофон "КАДР-3ПМ" состоит из следующих документов:

| Документ | Обозначение |
|---|---|
| Техническое описание | М181-600-000 ТО |
| Техническое описание | М181-600-000 ТО1 |
| Схемы электрические принципиальные к ТО1 | М181-600-000 ТО1, Приложение 1 – 2 части |
| Техническое описание | М181-600-000 ТО2 |
| Схемы электрические принципиальные к ТО2 | М181-600-000 ТО2, Приложение 2 |
| Техническое описание | М181-600-000 ТО3 |
| Схемы электрические принципиальные к ТО3 | М181-600-000 ТО3, Приложение 3 |
| Техническое описание | М181-600-000 ТО4 |
| Схемы электрические принципиальные к ТО4 | М181-600-000 ТО4, Приложение 4 – 2 части |
| Схема электрическая соединений | М181-700-000 Э4.1 |
