положение регуляторов тока записи каждого канала, которые соответствуют наибольшему показанию индикатора при воспроизведении. При этом необходимо установить регулятор ПОЛОЖЕНИЕ ГОЛОВОК так, чтобы отклонение стрелки индикатора было максимальным, а колебания ее из-за качаний двигателя - минимальны. Если наибольшему показанию индикатора при воспроизведении соответствует несколько значений тока записи, то из них следует выбрать наименьшее.

6.11.9. После этого необходимо зафиксировать найденные оптимальные значения токов записи для данного блока головок в паспорте блока.

6.11.10. После этого необходимо произвести контрольную запись. При этом после включения режима "Запись" необходимо установить соответствующие значения токов записи по индикатору.
